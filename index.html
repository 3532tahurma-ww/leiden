Haftalık Giriş

Sermaye değerleri haftanın son girilen gününe yazılır; boş bırakırsan son bilinen değerler korunur.

Veri · Kayıt & Senkron

Veri

Tüm Leiden verisi (La Merite, Thistle, Nivose, Edina Haritası) tek bir JSON dosyasıdır. Dosya olarak indirebilir ya da doğrudan GitHub reposuna kaydedebilirsin.

GitHub Senkronu

Veri, aşağıdaki repodaki JSON dosyasına GitHub API ile yazılır. Token yalnızca bu tarayıcıda saklanır, dosyaya yazılmaz.

Token: GitHub → Settings → Developer settings → Fine-grained tokens → Generate. "Only select repositories" ile sadece veri reposunu seç, Repository permissions → Contents: Read and write.
Repo herkese açıksa (public) veri dosyası da herkese açık olur. Veriyi private bir repoda tutmanı öneririm. Sayfa başka bir repoda GitHub Pages ile yayınlanabilir.

Dosya

Tüm veriyi .json olarak indir ya da daha önce indirdiğin bir yedeği geri yükle. Eski MR yedekleri de içe aktarılabilir.
